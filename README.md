# Ealy-Aramaic

Some font metrics based on Noto-Aramaic from GitHub - look at https://notofonts.github.io/imperial-aramaic.
The rest of font metrics are based on Cardo made by "The Cardo Project" authors (https://github.com/googlefonts/CardoFont)

For information on how to work on Noto fonts, how the build process
works and how to maintain it, see [the README file of the
notofonts.github.io
repository](https://github.com/notofonts/notofonts.github.io/blob/main/README.md)
